# Installation Instructions

You can set up `kmeans-pytorch` using one of the following two methods:

## Option 1: Install via pip 

Run the following command in your terminal:

```bash
pip install kmeans-pytorch
```

## Option 2: Manual Download (Recommended)

1. Download the source code from https://github.com/subhadarship/kmeans_pytorch.
2. Place the downloaded kmeans_pytorch folder into current working directory.
